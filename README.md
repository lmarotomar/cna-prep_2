# CNA Exam ProMaster (Simulador Bilingüe)

Simulador profesional bilingüe (Inglés/Español) para la preparación del examen de certificación CNA (Certified Nursing Assistant) bajo los estándares de ProMetric.

## Características Principales

- **360 Preguntas de Nivel Experto**: Distribuidas en 6 simulacros mixtos de 60 preguntas cada uno.
- **Modo Bilingüe Inteligente**: Soporte para estudiar en Inglés, Español o ambos simultáneamente.
- **Sistema de Revisión Post-Examen**: Identificación automática de errores con explicaciones detalladas y numeración de preguntas.
- **Persistencia de Puntaje**: Seguimiento de progreso por batería mediante almacenamiento local.
- **Diseño Premium**: Interfaz moderna, responsiva y optimizada para el estudio intensivo.

## Estructura del Proyecto

- `index.html`: Dashboard principal de selección de simulacros.
- `exam.html`: Portal de examen interactivo con temporizador y sistema de revisión.
- `css/styles.css`: Sistema de diseño basado en CSS moderno.
- `js/questions.js`: Base de datos centralizada de 360 preguntas bilingües.
- `js/app.js`: Lógica central del simulador y gestión de estados.

## Cómo Usar

Simplemente abre `index.html` en cualquier navegador moderno para comenzar. No requiere servidor backend, funciona completamente en el lado del cliente.

## Créditos

Desarrollado para la excelencia en la formación de profesionales de enfermería.
